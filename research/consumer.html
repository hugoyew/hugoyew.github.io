Consumer 消费行业研究框架

饮料、餐饮连锁、零售、品牌、食品 ToB、家居建材的方法论地图。

涵盖饮料、餐饮连锁、零售、品牌、食品 ToB、家居建材等子赛道。

框架以 三表（IS/BS/CFS） 为纵向骨架，每个科目先讲通用逻辑，再用 bullet 区分细分赛道差异。

一、行业特征

消费赛道覆盖面广，不同子赛道的生意本质差异大，但有以下共性分析要素：

  • 标准化程度 = 可规模化程度（尤其餐饮）：食材/工艺/店型越标准，复制阻力越小
  • 时尚风险是最大敌人（水 < 饮料 < 服饰）：越低越好，决定毛利率的可持续性
  • 渠道壁垒比产品差异更具护城河价值：货架有限、经销商体系锁定、先入优势
  • 下游分散度决定议价权归属：客户集中度低 → 品牌方话语权强，反之亦然
  • 消费降级的冲击是非对称的：不同价格带韧性分层，800+和快餐最抗跌，100-300最受伤

二、三表分析框架

2.1 利润表（Income Statement）

收入 Revenue

通用逻辑

消费行业收入可拆为 量 × 价：

  • 量：门店数 × 单店营收 / 用户数 × 客单价 / 渠道覆盖 × 渗透率（PSD）
  • 价：客单价/ASP、提价能力、折扣/调价策略

需求验证信号：对 ToB 生意而言，供小于求是最强信号——产品够好 → 客户回头 → 产能不够用。判断品质壁垒时要拆到原料一致性、工艺精细度、设备先进性三个可验证维度，不能笼统说"产品好"。

增长质量的拆解：同店增长 vs 新店/新客增长。同店增长说明 PMF 存在、开店只是复制成功；同店下滑 + 开店增长说明用增量掩盖存量恶化，不可持续——新店开到一定密度后会分流存量客户，形成负向螺旋。评估消费公司时，同店趋势比整体收入增速更具信息价值。

消费下行期的价格带韧性：消费降级的冲击是非对称的——高端餐饮（800+）和底层快餐受影响最小，大众正餐（100-300）最受伤，因为消费者的替代选择最多（降频或转向老乡鸡这类低价替代）。评估消费品牌时，价格带定位是第一道过滤器。

收入结构的三个维度：

  • ToC vs ToB：ToC 毛利率高但获客成本也高；ToB 订单确定性强但议价权弱
  • 自营 vs 渠道：自营利润率高但扩张慢，渠道快但让利给中间环节
  • 产品 vs 服务：服务收入通常更稳定、毛利更高

细分差异：

  • 餐饮连锁：收入驱动力 = 门店数 × 单店日销 × 营业天数。增长质量看同店（先导指标）vs 新店的拆分。同店韧性与城市线级强相关：低线城市加密程度高的品牌下滑更少（高线城市可支配收入压力大、竞争更激烈）。门店模型迭代能力（460㎡→300㎡）反映管理层对消费环境的理解——更小面积 = 更低盈亏平衡点。

- 来源：巴奴、绿茶

  • 饮料：收入驱动力 = 渠道覆盖 × 品类渗透率（PSD）。渠道价值分层：餐饮/特区 > 传统通路（货架有限→进入难→价值高）。品类选择决定时尚风险：水 < 功能饮料 < 茶饮。

- 来源：元生笔记

  • 食品 ToB / ODM：收入由客户订单驱动，增长天花板取决于合作客户的扩张而非自有品牌势能。代工厂的"被动创新"（柔性生产、快速响应热点）服务于客户需求，价值分配不均——代工厂承担执行风险，品牌方获取市场溢价。判断代工厂能否将被动创新转化为主动溢价，看它是否在客户关系中有更高利润分成。

- 来源：天鹰、加福面粉

  • 品牌/零售：收入依赖渠道控制力和品类属性。抖品牌天花板（脱骨侠案例）：严重依赖达播 → 渠道集中度高 → 转型方向为预制菜或上游供应链整合。品牌收入还需关注时尚风险（服饰/户外变化快、依赖行业β）。

- 来源：元生笔记

  • 家居建材：收入受新房 vs 旧改比例影响——新房占比高 = 地产周期敏感度高，旧改占比高 = 自然对冲。品类延伸是新增长来源（如淋浴房→全景门），可行性取决于材料和渠道的双重可迁移性，以及消费者认知是否到拐点。分散市场的集中度提升是收入增长的结构性β。

- 来源：玫瑰岛

毛利 Gross Profit

通用逻辑

毛利率 = 定价权 × 成本控制力。消费行业毛利受以下因素影响：

  • 原材料成本结构：农产品/食材价格周期、进口依赖（配额受限）、副产品价格波动（可影响毛利率数个百分点）
  • 供应链效率：自产 vs 外采、央厨覆盖率、产能利用率
  • 渠道利润分配：经销商层级数量、各级让利空间
  • 产品结构变化：高毛利品类占比升降（品类 mix shift）

关键判断：毛利率是否能在经济周期中保持稳定——这是品牌定价权和供应链控制力的综合体现。调价后毛利率不变（通过调整菜单结构而非压缩食材成本），说明品牌有供应链控制力；毛利率受损说明缺乏定价权。

产能爬坡期的毛利率失真：新工厂投产初期折旧和磨合成本会压低毛利率，这不代表盈利能力下降。要区分"短期爬坡压制"和"结构性恶化"——前者随产能利用率提升自然修复，满产稳态毛利率才是估值基准。

影响毛利的结构性趋势：Clean Label（减少添加剂，优质原料替代反而综合成本更低）和冷冻烘焙（CAGR 30%，渗透率<20% vs 欧美60%）都在改善行业毛利空间。

细分差异：

  • 餐饮连锁：食材成本占比（\~33%）决定基础毛利，央厨覆盖确保一致性但带来物流成本。大店面积缩小（460→300㎡）降低固定成本分摊。火锅fashion risk小、毛利稳定。标准化程度越高，毛利越可预测。

- 来源：巴奴

  • 饮料：一级经销商毛利3-4折，二级减半。毛利空间受原材料（水/糖/包装）价格周期影响。品牌力越强，经销商让利空间越小。
  • 食品 ToB / ODM：原材料成本受进口依赖和副产品价格波动影响。加工/成品端优于上游种植端（后者有天灾风险和库存审计模糊问题）。产能利用率是毛利杠杆——利用率越高，固定成本摊薄越多。

- 来源：加福面粉、天鹰

  • 家居建材：不同渠道毛利差异大——零售（\~40%）> 大宗（\~28%）> 出口（\~25%）。三角业务结构毛利差异源于客户类型和账期不同。

- 来源：玫瑰岛

费用 Operating Expenses

通用逻辑

消费行业费用结构反映生意模式：

  • 人力成本：餐饮/零售的核心费用，与标准化程度负相关（标准越高，对熟练工的依赖越低）
  • 租金：租售比（\~7-12%）是衡量选址效率的关键指标。固定 vs 浮动租金结构影响利润稳定性
  • 营销费用：品牌建设（长期）vs 效果投放（短期）的分配，直接影响获客效率和品牌价值积累
  • 物流/配送：央厨覆盖半径决定配送成本效率；冷链 vs 常温物流成本差异大
  • 管理费用：总部 vs 门店层面的费用分摊；门店扩张初期管理费用率通常偏高

店长/核心员工培养成本是餐饮连锁的隐性费用：店长对门店业绩负全责（类似海底捞），培养成功率约30%（考核淘汰+实战淘汰）。直营连锁的扩张瓶颈不是资金，而是店长供给pipeline的充裕度。店长培养周期长、淘汰率高本身就是护城河——体系一旦跑通，竞品难以短期复制。

细分差异：

  • 餐饮连锁：人力（\~31%）+ 租金（\~7.5%）+ 原材料（\~33%）是三大成本。央厨是一次性建设投入但持续降低单店运营成本。新店初始投入（200-500万）是前置成本，通过折旧摊销影响多年利润。
  • 品牌/零售：营销费用占比高，品牌建设 vs 效果投放的权衡影响长期竞争力。经销商模式下管理成本较低但渠道控制力弱。
  • 食品 ToB / ODM：管理费用与客户数量正相关（大客户多 → 对接团队大）。仓储物流费用随覆盖范围扩大而变化。
  • 家居建材：门店装修补贴和展会费用是一次性投入。经销商模式意味着门店费用由经销商承担，总部费用主要是管理和研发。

- 来源：玫瑰岛

净利率 Net Profit Margin

通用逻辑

净利率 = 毛利率 - 费用率 + 非经常性损益。关注：

  • 经营利润率 vs 净利润率：非经常性项目（重组、减值、IPO费用）是否在调整后利润中剥离
  • 净利润 → OCF 的转化率：盈利是否有现金支撑（见经营性现金流部分）
  • 净利润的波动来源：是毛利率波动（可持续的）还是费用率波动（可控的）

综合净利率参考区间（消费行业）：

  • 餐饮连锁：\~10-20%（巴奴\~20%、绿茶\~9-10%）
  • 饮料：15-30%（品牌力驱动）
  • 食品ToB/ODM：6-12%（产能利用率影响大，天鹰6%→12%爬坡）
  • 家居建材：\~10%（玫瑰岛），零售>大宗>出口

2.2 资产负债表（Balance Sheet）

应收账款 AR

通用逻辑

消费行业应收的结构和质量直接反映渠道控制力和客户结构：

  • 账期结构：现结/预收（正数营运资本）vs 授信（负数营运资本）
  • 客户集中度：最大经销商/客户占比越低，AR风险越分散，但也要考虑高质量客户的筛选效应
  • 关联交易风险：如果大客户同时是股东/合作伙伴，AR定价和回款节奏可能不反映真实市场水平

最大经销商占比是衡量渠道控制力的关键指标：农夫山泉\~1%（强控制力）vs 果子熟了\~5%（经销商话语权强→窜货/倒逼降价风险）。一般原则：占比越低，品牌方话语权越强。

ToB 客户结构的判断：前20%客户占多少业务量？如果"28效应"弱（前20%只占50%），说明下游高度分散——既是风险（客户拓展成本高）也是机会（整合空间大）。

细分差异：

  • 餐饮连锁：基本现结/预收，应收极少。即使有授信也周期短、质量高。
  • 饮料/零售：经销商体系决定是先款后货还是授信。渠道控制力强的品牌可以要求更短账期。
  • 食品 ToB / ODM：大客户授信、账期普遍较长。ODM客户集中度高→AR集中度风险大。关联交易的定价和回款需额外审计。

- 来源：天鹰（光明合资公司50%+订单）、加福面粉

  • 家居建材：大宗业务账期长、占用资金（玫瑰岛：地产业务账期明显长于酒店业务先款后货）。这是三角业务中最影响现金的环节。

- 来源：玫瑰岛

存货 Inventory

通用逻辑

消费行业存货管理是经营能力的重要指标：

  • 存货结构：原材料 / 在制品 / 产成品的比例
  • 周转天数：与供应链模式直接相关（央厨>门店>消费者链路）
  • 跌价/减值风险：时尚风险（服饰>饮料>水）、保质期（餐饮食材）、技术迭代（消费电子）
  • 库存管理策略：跌价时囤货、涨价时释放（储备策略）平滑毛利率

大宗贸易的库存管理逻辑：针对原材料价格波动，核心手段是储备策略（跌价时囤、涨价时放）平滑毛利率，以及技术手段降低对副产品价格的依赖（如提高出粉率减少残值）。

  • 来源：加福面粉

细分差异：

  • 餐饮连锁：食材周转快（天/周级别）、保质期短、供应链要求高。央厨模式减少门店库存压力。
  • 食品 ToB：原材料占比高，进口依赖带来配额风险和采购周期不确定性。加工/成品端存货价值高于种植端（后者有库存审计标准模糊的问题）。
  • 家居建材：定制化产品以销定产、存货风险低；标品需要备货、有跌价风险。

固定资产 PP&E

通用逻辑

消费行业的固定资产结构反映生意是资产重型还是轻资产：

$\text{单店/单位经济模型} \rightarrow \text{初始投入} \rightarrow \text{回收期} \rightarrow \text{扩张速度上限}$

  • 单店投入越小、回本越快 → 规模化阻力越小（茶颜/古茗/蜜雪：\~20万、3个月回本 vs 乐刻：\~130万、3年回本）
  • 产能型资产（央厨/工厂）决定扩张边界：当产能利用率接近饱和（80%+），扩张速度自然放缓直到新产能投产
  • 资产折旧政策影响利润透明度：Capex 摊销带来的短期利润增长，看 EBITDA 就行

细分差异：

  • 餐饮连锁：单店投入（200-500万）+ 央厨（千万级）。央厨覆盖半径（\~600km）天然限制扩张范围——在现有区域加密 vs 跨区域建新央厨，增长驱动和资本需求完全不同。店型迭代（如460→300㎡）可以降低盈亏平衡点。

- 来源：巴奴（500万/店、14个月回本）、绿茶（200万/店）、茶颜/古茗/蜜雪（20万/店、3个月回本）

  • 食品 ToB / ODM：工厂建设和产线是主要资产。产能爬坡期利润率有误导性，满产稳态利润率才是估值基准。产能弹性（如通过调整班次）可短期突破名义上限。

- 来源：天鹰（新工厂投入2.3亿）

  • 家居建材：经销商门店投入由经销商承担（\~60-70万/200㎡），总部投入主要在工厂。好的经销商UE（一年内回本）是渠道扩张的基础，但下沉市场客单价能否支撑同样UE是关键问题。

- 来源：玫瑰岛

负债与杠杆

通用逻辑

消费行业负债结构反映运营效率和扩张策略：

  • 应付账款：对供应商的议价权体现为账期长短
  • 租赁负债（IFRS 16）：餐饮/零售的核心负债来源
  • 预收 / 合同负债：品牌力的体现（会员充值、预付费卡）
  • 有息负债：扩张期的杠杆使用（开店Capex vs 自有资金）

细分差异：

  • 餐饮连锁：租赁负债高（IFRS 16后表内化），但通常无大量有息负债——开店靠经营性现金流滚动。流动性好、负债率低。
  • 食品 ToB / ODM：供应商应付账款和客户应收账款的匹配是关键。扩张时可能借债建设产能（天鹰新工厂），但理想状态是靠经营现金流覆盖。
  • 家居建材：大宗业务占用资金（地产账期长），需要营运资本支撑。酒店业务先款后货是优质负债来源。

- 来源：玫瑰岛

2.3 现金流量表（Cash Flow Statement）

经营性现金流 OCF

通用逻辑

消费行业 OCF 质量的核心指标：OCF / 净利润 比率。

  • OCF > 净利润：说明利润质量高，营运资本管理好（现结/预收模式）
  • OCF < 净利润：说明利润中有大量应收/存货占用，或存在非现金收入
  • 增长与现金流的矛盾：当增长靠开店/扩产驱动时，OCF 可能被营运资本扩张吞噬

判断标准：消费公司盈利能力要看净利润 → OCF 的转化率。高利润+低OCF是危险信号。

细分差异：

  • 餐饮连锁：现结模式，OCF/净利润通常 > 1。但高速开店期现金流可能紧张（新店需要前置投入）。
  • 食品 ToB / ODM：账期影响大，OCF 可能低于净利润。客户集中度越高，AR 对 OCF 的影响越大。
  • 家居建材：零售业务贡献优质现金流（现结），大宗业务占用资金（账期）。三角业务之间的现金流质量差异显著。

- 来源：玫瑰岛

投资性现金流 ICF

通用逻辑

ICF 反映公司的增长战略和资产配置：

$\text{ICF} = \text{开店 Capex} + \text{产能/供应链 Capex} + \text{维护性 Capex}$

  • 增长性 Capex vs 维护性 Capex：前者是扩张信号，后者是维持运营成本
  • 单店投入回报率（初始投入 ÷ 年单店利润）决定 ICF 效率
  • Capex 强度（Capex/收入）反映重资产程度

细分差异：

  • 餐饮连锁：Capex = 新店 + 央厨/供应链。店型越小、Capex 越低、资产周转越快。央厨先投后收益，需要 2-3 年消化。
  • 食品 ToB / ODM：Capex = 新工厂 + 产线扩容。产能利用率从爬坡到满产需要 12-18 个月。
  • 家居建材：Capex = 工厂（总部）+ 门店展示（经销商承担，表外）。相对轻资产。

- 来源：玫瑰岛

自由现金流 FCF 与回报

通用逻辑

$\text{FCF} = \text{OCF} - \text{维护性 Capex}$

  • FCF 转化率（FCF/净利润）：衡量利润的现金真实度
  • FCF 与增长的关系：增长是否消耗现金流？健康的消费公司应该在增长的同时保持正 FCF
  • 单店 FCF：消费连锁的核心分析单位——单店 FCF × 门店数 = 公司整体 FCF

"增长消耗现金流" vs "增长产生现金流" 的判断：前者的例子是自营重资产模型（ROIC 低于 WACC），后者的例子是品牌授权或平台轻资产模型。

细分差异：

  • 餐饮连锁：单店FCF = 单店利润 - 维护性Capex。好的品牌单店FCF稳定为正，开店扩张期整体FCF可能为负但投入期短（14个月回收）。
  • 食品 ToB / ODM：产能扩张期 FCF 承压，满产后 FCF 改善。FCF 的波动性比净利润大，评估时需看完整产能周期。
  • 家居建材：零售业务贡献优质 FCF，大宗业务在扩张期占用 FCF。

- 来源：玫瑰岛
