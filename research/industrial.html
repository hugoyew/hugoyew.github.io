Industrial 工业行业研究框架

制造业、新能源、生产要素型生意、供应链与农业。

涵盖制造业、新能源、生产要素型生意、供应链、农业等重资产行业。

框架以 三表（IS/BS/CFS） 为纵向骨架，每个科目先讲通用逻辑，再用 bullet 区分细分赛道差异。

一、行业特征

  • 重资本开支（Capex）：大量前期投入 + 长等待周期，ROIC 天然低于轻资产行业
  • 周期性：供需关系、原材料价格、宏观经济周期三重叠加，利润波动大
  • 受生产要素约束：牌照、产能、自然资源决定供给上限——"看天吃饭，和挖矿差不多"
  • 规模效应明显，但扩张依赖资本投入而非品牌溢价
  • 产能利用率是利润的杠杆：固定成本占比高，利用率差几个点就是盈亏之别
  • "表前" vs "表后"的区分：表前（utility-scale）是成本竞赛，表后（behind-the-meter）可能更接近消费品逻辑

二、三表分析框架

2.1 利润表（Income Statement）

收入 Revenue

通用逻辑

工业收入驱动的核心公式：

$\text{收入} = \text{产能} \times \text{产能利用率} \times \text{产品均价}$

三个变量各有不同的驱动力和风险：

  • 产能：由已投产的工厂/产线/牌照决定，是供给上限。扩产周期长（12-36 个月），意味着收入增长在短期内受到物理约束
  • 产能利用率：决定固定成本摊薄的效率。利用率从 80% 到 95% 可能意味着利润翻倍——因为固定成本不变，增量收入几乎全部转化为利润
  • 产品均价：受供需关系、原材料价格、客户结构（国内 vs 海外）影响大

增长驱动因素：

  • 量的增长：新产能投产（新工厂、新产线、新牌照）
  • 价的增长：产品结构升级（从低毛利标品到高毛利差异化产品）
  • 客户结构升级：从国内（低毛利、价格驱动）到海外（高毛利、解决方案驱动）
  • 行业β：需求增长超预期（如储能行业年预测 300GWh 实际 500GWh+）

国内 vs 海外两个市场，两门不同的生意：国内是"计划经济"（国央企招标、价格权重高、毛利 8-12%），海外是解决方案竞争（认证/案例/服务 > 价格，毛利可达 30%+）。同一家公司在两个市场的利润率差距可达 3-4 倍。海外收入占比和海外扩张能力直接决定估值天花板。

细分差异：

  • 生产要素型（牌照/资源）：收入受供给侧约束——牌照增量空间（大洋世家捕捞牌照还有一倍空间？）、资源储量、产能上限。需求侧需验证：产出是否都能卖出？价格是否稳定？不存在"大小年"的意思是总量需求稳定，但价格仍有波动。

- 来源：大洋世家、厚全鸡蛋

  • 新能源 / 电池（表前）：收入由全球能源转型需求驱动，连续多年超预期。在增量市场中，头部有效产能反而稀缺——竞争核心是产能覆盖速度和客户获取能力，而非价格战。差异化产品（长时储能专用电芯）的产能壁垒更牢固。

- 来源：海辰储能

  • 新能源 / 表后储能：收入遵循消费品逻辑（品牌、渠道、终端用户），而非制造框架（产能、成本）。增长靠渠道渗透和安装商网络扩张——收入可见性取决于渠道覆盖的质量而非产能规划。

- 来源：思格新能源

  • 制造业 / 供应链：收入受客户订单驱动，增长靠客户拓展和品类延伸。客户结构变化直接影响收入质量（从高附加值向低附加值延伸稀释整体利润率）。业务聚焦度本身就是估值溢价依据——多元化公司"growth driver"难以清晰阐述是危险信号。

- 来源：蓝思科技

毛利 Gross Profit

通用逻辑

工业毛利 = 产品均价 - 单位成本。成本结构通常为：

$\text{单位成本} = \text{原材料} + \text{人工} + \text{能耗} + \text{折旧}$

毛利的核心驱动因子：

  • 原材料价格周期：农产品/矿石/化工品价格波动可影响毛利率数个百分点。进口依赖 + 配额限制是隐形成本
  • 产能利用率：利用率越高，单位固定成本越低——产能利用率是毛利最大的短期杠杆
  • 产品结构（mix shift）：高毛利差异化产品占比上升 vs 低毛利标品占比上升
  • 客户结构：海外 vs 国内、品牌客户 vs 白牌客户

产能爬坡期的毛利率失真：新工厂投产初期折旧和磨合成本压低毛利率，这不代表盈利能力下降——区分"短期爬坡压制"和"结构性恶化"，满产稳态毛利率才是估值基准。

国内 vs 海外毛利差异的原因：国内客户价格敏感度高（招标制），海外客户关注认证/服务/稳定性（解决方案制）。这不是暂时的套利，而是两种生意模式的本质差异。

细分差异：

  • 生产要素型：毛利率受牌照稀缺性和资源品位影响大。牌照越稀缺、资源品位越高 → 毛利率越高、越稳定。
  • 新能源 / 电池（表前）：毛利率从国内（\~8%）到海外（\~30%+）跃升是最大特点。海外毛利率高但需要前期投入（认证、本地化产能、品牌建设）。原材料（锂/钴/镍）价格周期对毛利率影响大。

- 来源：海辰储能

  • 新能源 / 表后储能：毛利率受渠道结构影响——经销商加价+安装商加价是渠道成本结构的核心。产品集成度（一体机 vs 分体式）决定了安装效率，间接影响渠道毛利分配。电芯外采意味着电池技术本身不是毛利壁垒。

- 来源：思格新能源

  • 制造业 / 供应链：毛利率的长期趋势反映公司战略——从高附加值向低附加值延伸（如零部件→组装）会拉低整体毛利率。关键是新增环节是否通过协同效应提升了核心业务的竞争地位？如果只是"把低利润环节纳入体内"，毛利率和ROIC都会承压。

- 来源：蓝思科技

费用 Operating Expenses

通用逻辑

工业费用结构比消费/TMT 简单，但有几个独特之处：

  • 折旧费用：工业公司最大的"非现金费用"，直接影响利润可视性。Capex 摊销带来的短期利润增长，看 EBITDA 就行
  • 管理费用：与生产规模和组织复杂度相关。出口业务的管理费用通常高于内销（多语言团队、海外合规）
  • 研发费用：工艺改进、产品迭代、认证测试。工业研发的转化周期比 TMT 长
  • 销售费用：ToB 模式下销售团队是核心。国内销售靠关系维护，海外销售靠认证+案例+渠道
  • 物流费用：原材料运输 + 成品配送。央厨/工厂覆盖半径决定配送成本效率

运营杠杆的威力：工业公司的固定成本占比高（折旧、人工），因此收入的小幅变动可以导致利润的大幅变动。阅读 IS 时，运营杠杆是比毛利率更重要的利润驱动因素。

细分差异：

  • 生产要素型：管理费用相对简单（人员少、流程固定）。如果需要大面积人力（如养殖业），人工成本是主要费用。
  • 新能源 / 电池：研发费用占比高（技术迭代快）。管理费用随海外扩张增加（海外团队、本地化运营）。认证和测试费用是进入海外市场的前置成本。

- 来源：海辰储能、思格新能源

  • 制造业 / 供应链：管理费用与客户数量和复杂度正相关。如果从几个大客户扩展到众多中小客户，管理费用率会上升。产品线越宽，研发和管理的复杂度越高。

- 来源：蓝思科技

净利率与盈利能力

通用逻辑

工业净利率区间相对集中，波动大：

类型 净利率区间 核心变量
牌照/资源型10-25%牌照稀缺性、资源价格周期
新能源（海外>国内）5-15%（国内8%，海外30%+加权）海外占比、产能利用率
表后储能15-20%渠道效率、产品集成度
先进制造8-15%产品结构、客户质量
传统制造（ODM/组装）5-12%产能利用率、客户集中度

核心判断：工业净利率的波动 > 绝对值——能够穿越周期保持净利率稳定的公司，通常有不可替代的供给优势（牌照、资源、技术认证）。

2.2 资产负债表（Balance Sheet）

固定资产 PP&E

通用逻辑

PP&E 是工业公司的核心资产，也是最重要的分析科目：

$\text{PP\&E（产能）} \rightarrow \text{利用率} \rightarrow \text{单位成本} \rightarrow \text{毛利率}$

  • 资产结构：工厂/产线/设备/矿山。不同类型资产的折旧年限和残值率不同
  • 产能利用率：决定固定成本摊薄效率。工业公司 80% 利用率 vs 95% 利用率可能是盈亏之差
  • 扩产周期：从决策到投产通常 12-36 个月——现在看到的产能是 1-2 年前的投资决策结果
  • 折旧政策：直线 vs 加速、使用年限假设——影响利润透明度

单/单位经济模型：工业的"单模型"不是单店而是单条产线 / 单个工厂——投入多少、多久回本、满产产出多少、单位成本曲线如何。

细分差异：

  • 生产要素型：产能是最核心的 BS 科目。扩产周期长（厚全鸡蛋：鸡舍建设周期），需要大量前期现金投入。产能利用率决定盈亏。

- 来源：厚全鸡蛋

  • 新能源 / 电池（表前）：工厂是最大资产。海辰三年迭代四代智能工厂，重庆工厂从绿地到满产仅用 13 个月——扩产速度本身是竞争壁垒。当产能利用率接近饱和（80%+），扩产速度会自然放缓。

- 来源：海辰储能

  • 新能源 / 表后储能：PP&E 相对轻——生产组装在国内，电芯外采。核心资产不在工厂而在品牌和渠道网络（在 BS 上不体现）。

- 来源：思格新能源

  • 制造业 / 供应链：PP&E 结构反映垂直整合深度——从核心零部件到整机组装，每个环节需要的资产类型不同。评估垂直整合时，要区分"向上整合（增强控制力）"和"向下延伸（争夺低利润组装）"——前者强化护城河，后者摊薄 ROIC。

- 来源：蓝思科技

存货 Inventory

通用逻辑

工业存货金额大、周期长，是 BS 上的重要科目：

  • 存货结构：原材料 / 在制品 / 产成品的比例——在制品占比高说明生产周期长
  • 价格风险：原材料价格下跌 → 存货减值（大宗商品尤其突出）
  • 周转天数：反映供应链效率。工业存货周转通常以月计（vs 餐饮以天计）

储备策略：针对原材料价格波动，核心手段是跌价时囤货、涨价时释放，平滑毛利率。技术手段（如提高出粉率降低副产品价格依赖）可以降低残值对成本的影响。

细分差异：

  • 生产要素型（资源/农业）：农产品库存有审计标准模糊的问题（生物资产估值难度大）。种植端有天灾风险，存货可能在短时间内大幅减值。加工/成品端存货价值更可预测。
  • 新能源 / 电池：原材料（锂/钴/镍）价格波动大，存货管理是核心能力。库存跌价准备的计提方式影响利润。
  • 制造业 / 供应链：原材料 + 在制品 + 产成品三者比例反映生产模式。定制化生产以销定产 → 存货风险低；标准化生产需要备货 → 有跌价风险。

应收账款 AR

通用逻辑

工业应收的结构反映客户类型和竞争地位：

  • 账期结构：新能源车/车企客户账期长（比亚迪每季度谈价、年降 20%、账期 3-6 个月）；国央企客户账期长但信誉好
  • 客户集中度：前五大客户占比越高 → AR 集中度风险越大
  • ToB 客户结构的判断：前 20% 客户占多少业务量？"28效应"弱（前20%只占50%）→ 下游分散，既是风险（拓展成本高）也是机会（整合空间大）

核心判断：工业 AR 的质量 = 客户质量 × 集中度 × 账期。国央企客户账期长但违约率低；中小客户账期短但违约风险高。

细分差异：

  • 新能源 / 电池（表前）：国央企客户为主，账期长但信誉好。海外客户通常预付+尾款，AR 质量优于国内。供应链金融可改善 AR 周转。

- 来源：海辰储能

  • 制造业 / 供应链：从高利润率顶级客户向低利润率普通客户扩展 → 客户集中度下降但 AR 质量也可能下降（顶级客户的高标准本身就是能力筛选器）。

- 来源：蓝思科技

  • 农业 / 食品供应链：下游高度分散 → 客户拓展成本高，但 AR 风险也相对分散。

无形资产与牌照

通用逻辑

工业的无形资产与传统认知不同——牌照/配额有时比专利更有价值：

  • 牌照 / 配额：生产要素型生意的核心资产（远洋捕捞牌照、采矿权、排污指标）。牌照的稀缺性决定生意可复制性
  • 技术 / 专利：制造业的技术壁垒通常体现在工艺know-how而非IP保护
  • 客户关系：ToB 业务中，长期客户关系是重要的无形资产（但不体现在 BS 上）

牌照价值的评估：获取难度（行政壁垒高 ≠ 价值高）、增量空间（还有多少空间？）、价格/利润弹性。

负债与杠杆

通用逻辑

工业公司负债率通常较高，因为重 Capex 天然需要融资：

  • 银行贷款：最普遍的融资方式，利率和期限影响财务费用
  • 供应链金融：对供应商的应付账款（信誉好的公司可以占用供应商资金）
  • 融资租赁：设备融资的常见方式
  • 项目贷款：大型基建项目的专项融资

核心判断：工业公司的杠杆应该用"EBITDA 覆盖倍数"而非"资产负债率"衡量——利息覆盖倍数 > 3x 是安全线。

2.3 现金流量表（Cash Flow Statement）

经营性现金流 OCF

通用逻辑

工业 OCF 的特征：

  • 净利润 → OCF 的转化率通常 < 1（因为高折旧 + 高应收 + 高存货占用）
  • OCF 波动性比净利润大（营运资本变动受原材料价格和客户付款节奏影响）
  • 产能扩张期 OCF 承压（新产能投产前需要投入大量现金）
  • OCF 改善的信号：产能利用率提升 → 存货周转加快 → 应收回款改善

OCF 是工业投资中比净利润更真实的业绩指标——因为折旧和摊销是人为判断，而 OCF 是实际现金流入。

细分差异：

  • 生产要素型：OCF 取决于牌照/资源的变现效率和客户回款周期。如果牌照稀缺且需求稳定，OCF 质量高。
  • 新能源 / 电池：海外业务（高毛利、可能预付）贡献优质 OCF；国内业务（低毛利、账期长）贡献差。海外收入占比提升直接改善 OCF。

- 来源：海辰储能

  • 制造业 / 供应链：垂直整合越深，OCF 压力越大（每个环节都需要运营资金）。从零部件延伸到整机组装 → 营运资本需求增加 → OCF 承压。

- 来源：蓝思科技

投资性现金流 ICF

通用逻辑

工业的 ICF 是增长的前置信号：

$\text{ICF} = \text{新产能 Capex} + \text{维护性 Capex} + \text{M\&A 支出}$

  • 新产能 Capex：反映管理层的增长预期和对未来的信心。当前 ICF 是未来 1-3 年的收入增长来源
  • 维护性 Capex：维持现有产能运转的必要支出，通常占 PP&E 的 2-5%/年
  • ICF / 折旧比率：> 1 表示公司在真实扩张（不只是维护）；< 1 表示公司可能处于收缩期

核心判断：工业 Capex 应该用"未来增量收入/利润"来评估回报率，而不是用当前产能利用率评估。一个在建工厂可能拉低当前利润，但投产后 2-3 年是增长引擎。

细分差异：

  • 生产要素型：ICF 取决于产能扩张计划。牌照类公司 ICF 可能很低（牌照靠拿、产能靠牌照，不需要大量建设投入）。
  • 新能源 / 电池：ICF 极高——产线迭代快（海辰三年四代工厂），持续投入是维持竞争力的必要条件。本地化产能建设（海外工厂）是新的 ICF 增量。

- 来源：海辰储能、思格新能源

  • 制造业 / 供应链：ICF 反映垂直整合的战略方向——向上整合（收购上游原材料/零部件供应商）vs 向下延伸（自建组装产线）。方向决定 ICF 是增强护城河还是摊薄 ROIC。

- 来源：蓝思科技

自由现金流 FCF 与回报

通用逻辑

工业 FCF 的特征：

$\text{FCF} = \text{OCF} - \text{维护性 Capex}$

  • 工业 FCF 天然偏低（高 Capex + 高营运资本占用），但这不一定是坏事——关键在于 Capex 的回报率
  • FCF / 净利润比率：工业通常 < 0.5（vs 平台/SaaS > 1）
  • 周期性的 FCF：底部扩张（Capex 高、利润低 → FCF 极低）、顶部收缩（Capex 低、利润高 → FCF 极高）

核心判断：工业公司的投资价值不是看当前 FCF 而是看未来 FCF 的折现值——当前的大量 Capex 是未来 FCF 的来源。但需要确认：Capex 是否在创造真实的竞争优势（比竞争对手更低的成本/更高的效率/更快的扩产速度）？
