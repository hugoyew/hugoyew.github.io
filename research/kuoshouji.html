折叠屏 → 阔手机：品类迁移的早期判断与跟踪。

折叠屏 → 阔手机，但不好。数据截至 2026-08-26。

0. 摘要

立场： 阔手机（阔直板 · 阔折叠）是折叠屏价值的「去铰链化」拆解实验——折叠屏 = 面积跃迁 + 形态切换 + 宽比例，三合一打包；阔直板只把其中「宽比例」一个成分抽出来单卖。内容逻辑成立（长视频 / 图文 / 阅读在横屏原生下是真实升级），但池子 ⊂ 折叠买家（轻办公 / 高端商务，百万台级），且软件（短视频 #1）＋ 硬件（单手 / 口袋 / 配件）双重不适配 → 高端 niche，不是主流答案。

落地点（趋势读数）： 折 > 宽。折叠解决的是「大屏 vs 便携」这个更根本的矛盾；宽只是比例修正。阔手机的真正价值是成为一场成分拆解实验——阔直板的销量会告诉我们，用户为折叠买单的核心到底是「大」「宽」还是「折」。上限看短视频生态是否适配。

论证骨架：

  1. Hypo：折叠屏成功 → 苹果卡位 → 全行业做阔手机——但不好。
  2. 证据1 · 电池：手机电池容量 ∝ XY 面积 → 阔直板 7000mAh 是四形态最大；阔折叠（4720-5300mAh）受结构惩罚。
  3. 证据2 · 软件不适配：短视频 137min #1 是最大冲突，长视频 \~80min / 图文适配 ✓；第三方 app 适配滞后 12-24 个月。
  4. 证据3 · 硬件不适配：单手/小手、口袋/包包、配件全不适配——手小用户一票否决。
  5. 结论：折 > 宽；阔直板是成分拆解实验，池子 ⊂ 折叠买家。

1. Hypo：折叠屏 → 阔手机，但不好

折叠屏品类的成功，驱动全行业做「阔」形态的手机——但这不是一个 wise choice。

  • 折叠屏确实成功：2025 年中国折叠屏出货 892 万台（+42%），2026Q1 280 万台（+65%）；华为 Pura X 单款一年 154 万台。
  • 动因：华为造出品类 → 销量验证（154 万台）→ 苹果阔折叠入局前的卡位战 → 全行业跟进。
  • 两个形态分开：阔折叠（小米 18 Fold、华为 Pura X / X Max，贵·有铰链）vs 阔直板（华为 Pura X View，去铰链·5999·7000mAh）。

2. 证据1 · 电池

能量密度固定的前提下，长续航 = 加体积。手机电池是扁平 pouch cell，厚度固定下容量 ∝ XY 面积——加宽直接给电池加面积。

形态 代表 电池 结论
小直板\~6.1"\~4000-4500mAh足迹最小，容量上限最低
窄直板6.3-6.7" 20:9\~5000-5500mAh硅碳负极在往 6000 走
阔直板Pura X View7000mAh四形态最大——面积∝容量 + 去铰链
阔折叠Pura X / Max4720 / 5300mAh铰链 + 双屏吃空间（结构惩罚）
  • 结论：阔直板电池是加分项（四形态最大）；被结构惩罚的是阔折叠。
  • 补充：更宽更亮的屏也更耗电，实际续航增益 < 容量增益（7000 vs 6000 ≈ +17%，屏幕面积也 +\~17%）。
  • 反充电宝：7000mAh + 长续航降低外接电源依赖；充电宝 TAM 被压缩是趋势读数的附带信号（见 §6），不展开成标的。

3.2 「横屏原生」展开

  • 是什么：手机横持成为主用法，16:9.5 横屏 ≈ 小平板/一本书；内容不再被 20:9 竖长屏的窄栏和大黑边惩罚。
  • 为什么是真实升级：① 视频比例匹配（16:9 几乎满屏，+16% 显示面积）；② 阅读信息密度（小红书三列→四列、PDF/文档免缩放）；③ 同对角线比 20:9 多 \~17% 显示面积（A = d²·r/(1+r²)）。
  • 核心矛盾：时间占比第一的短视频是 9:16 竖屏，横屏原生用户必须转回竖持——宽屏牺牲「高时长」的短视频，去讨好「高质量时长」的阅读/长视频/图文。品类上限取决于短视频平台是否愿意改版。

3.3 app 适配滞后

  • 第三方 app 普遍存在拉伸变形、按钮错位、黑边。
  • 中国旗舰 app（微信/抖音/游戏）对 16:9.5 的适配可能 12-24 个月到位（HarmonyOS 官方强推）；国际市场与长尾 app 更慢甚至永久不适配。

4. 证据3 · 硬件不适配（物理）

硬伤：软件不适配能靠升级修，物理不适配是结构性的、软件改不了。

  • 单手 / 小手：拇指够不到对角、虎口酸、返回键要刻意够——手小的人直接一票否决（个人视角：我是小手，可能天然更难理解这种形态的价值）。
  • 口袋 / 包包：撑裤袋、卡腿、坐下有顶触感。
  • 配件生态：充电宝、手机支架、保护壳、车载支架全都不适配；物理配套只能等软件跑通后才跟进 → 前期体验打折。
  • 历史定位：宽屏改变的是「握持比例」（变宽变短），更接近 LG Optimus Vu（2012，5" 4:3 阅读优先，一代而亡）的失败模板，而不是 phablet（只是变大、握持逻辑没变）的成功模板。

5. 结论与落点

  1. 折 > 宽：折叠的价值 = 面积跃迁 + 形态切换 + 宽比例；阔直板只保留「宽比例」，丢了面积和切换。宽是折的派生物，不是更本质的东西。
  2. 内容逻辑成立，但池子不大：长视频 / 图文 / 阅读在横屏原生下是真实升级；但阔直板服务的池子 ⊂ 折叠买家（轻办公 / 高端商务）。折叠屏总量已被验证是百万台级（892 万台 / 年），阔直板还要更窄——只服务「只要宽、不要大」的人。时长结构上，宽屏适配的是注意力少数派（长视频 + 图文 + 办公 < 1/3；短视频 + 游戏 > 2/3 且不适配）。
  3. 软件 + 硬件双重不适配：短视频（时间 #1）是软件侧最大矛盾；单手 / 口袋 / 配件是硬件侧结构性硬伤——两者把阔手机锁死在小众。
  4. 落地点 = 成分拆解实验：用户为折叠买单，买的是「大」「宽」还是「折」？阔直板销量是判别证据：

- 卖不动 → 用户买的是「大」或「折」→ 折叠独大，宽比例独立不成立

- 放量、分流折叠 → 用户买的是「宽」→ 铰链溢价被侵蚀，宽比例能独立成立

  1. 立场：高端 niche，非主流答案。上限看短视频生态是否适配。

6. 趋势读数

不找标的，读趋势。阔手机本身是形态 niche，但它是一场可观察的实验：

  • 观察变量：阔直板（Pura X View）销量 vs 折叠屏销量。

- 阔直板放量、分流折叠 → 「宽比例」在折叠价值里权重高，折叠的铰链溢价被侵蚀。

- 阔直板卖不动 → 用户买折叠是买「大」和「折」，宽比例独立不成立。

  • 主线不变：显示面积与电池密度两大军备竞赛是真正的主线，阔手机只是观察窗（去铰链化 = 面积军备的价格下沉；7000mAh = 电池密度军备）。
  • 顺带信号：若「宽」独立成立，折叠屏的铰链 / 折痕相关价值量会被稀释（不展开成标的）。
