万店连锁 × 渠道-供应链-心智识别框架

从蜜雪到瑞幸：万店连锁背后的渠道、供应链与心智三层识别框架。

本文由三份笔记合并：中金《万店连锁专题#1》研报整理 + 解读批判 + 思考推进（现制茶饮≈RTD、压货机制）+ 收敛出的公司识别框架。

一句话总览：万店的门槛不在数量，在网络能否自我养活；找好企业 = 找到该生意当前"绑定约束"的那一层，看它是否在持续加固；识别坏企业 = 看它是否在非绑定层透支增长（压货 / 透支开店），用 sell-in 掩盖 sell-through 的恶化。

起因

  • 读到中金研究部 2026-08-17《万店连锁专题#1：何以万店，何止万店》，内容喜欢，完整整理入 Vault
  • 报告框架：万店基因（标准化 × 亲民定价 × 扩张模式）→ 万店能力（"三柱一基"）→ 万店之后（广度 / 深度 / 效率）→ 万店投资（成长 × 价值，中国龙头折价约 54%）
  • 整理后产生两个追问：

1. 报告偏"规模信仰"，它的暗面在哪？

2. 若现制茶饮近似 RTD（供应链核心 + 爆品），那么 RTD 里"元气森林红极一时 → 压货 → 爆"的故事，在现制茶饮里对应什么？

A.0 摘要 / TL;DR

  • 万店基因 = 标准化扩张 × 亲民定价 × 因地制宜的扩张模式
  • 万店能力 = "三柱一基"：供应链 + 加盟商/门店管理 + 品牌建设，数字化为底座
  • 万店之后 = 从"门店复制"到"能力复用"，向广度（国内加密+出海）、深度（品类/品质/品牌）、效率（链路压缩/规模效应/价值链重塑）要增长
  • 投资 = 成长性 × 价值性二维框架；中国服务消费龙头较海外系统性折价（远期 P/E 海外 28.8x vs 国内 13.3x，折价约 54%）
  • 风险：消费需求承压、行业竞争加剧、管理能力提升不及预期

A.1 何以万店：万店基因

万店基因源于对生意属性、定价定位、扩张模式三者的系统性选择。

A.1.1 生意属性：标准化 = 可规模化

  • 产品标准化：前置生产 / 轻度加工的产品更易标准复制
  • 服务标准化：轻度服务通过 SOP、设备、培训降低对人的依赖
  • 数据：量贩零食连锁化率 92%、现制饮品 49%

A.1.2 定价定位：大众价格 + 渗透下沉

  • 2025 年市场规模：现制饮品 7,464 亿 / 西式快餐 3,280 亿 / 零食饮料零售 43,079 亿元
  • "三买"：买得起（低门槛）、买得值（规模化供应链→高质平价）、买得到（深度覆盖下沉市场，占比普遍高于三线及以下城市社零占比 47%）
  • 万店业态普遍"小店型、轻投入"：缩短回本周期，撬动社会资本

A.1.3 扩张模式：直营 vs 加盟的权衡

取决于三因素：管理复杂度（越高越需直营）、外部资源依赖（越高越适合加盟）、供应链与数字化能力（放开加盟的前提）。

路径 适用 代表
先直营后加盟管理复杂度适中，高线起步向下沉渗透瑞幸、肯德基
始终加盟主导管理复杂度较低，以下沉市场为核心蜜雪、古茗、好想来
始终直营主导管理复杂度高，以高线城市为核心星巴克、太二酸菜鱼

A.2 万店能力："三柱一基"

生意属性/定价定位/扩张模式决定万店基因，而"三柱一基"决定基因能否被持续兑现。

A.2.1 供应链能力（柱一）

  • 上游原料获取 + 中游生产加工 + 下游仓配网络
  • 强供应链能力优先于大单品创新能力：产品复杂度低、易被模仿，只有供应链能支撑持续迭代与稳定交付（库迪反例：供应链跟不上 → 大单品多次缺货）
  • 三条决策逻辑：

1. 平价品牌重视全产业链把控（蜜雪掌控采购/加工/仓配全链条，6-7 元价格带）

2. 门店越下沉，越需自建仓配（古茗自建冷链布局乡镇；量贩零食自建仓配）

3. 原料复杂度决定外部合作形式（瑞幸咖啡豆大宗 → 源头直采+自建烘焙；百胜中国原料复杂 → 本土第三方深度合作）

  • 中外对比：大部分中国万店品牌自建供应链；海外龙头如麦当劳完全依赖外部供应商

A.2.2 加盟商管理与门店运营（柱二）

千店→万店，瓶颈从"能否招到加盟商"转向"能否持续创造有竞争力的单店回报并在更大网络中稳定复制"。

  • 健康单店模型：投资门槛低 + 回笼快 → "单店盈利—加盟商复投—门店加密"循环；成熟单店回收期 \~2 年

- 2022-2025：蜜雪/古茗加盟商数量 CAGR 26%/42%，加盟门店 CAGR 均 27% → 59,785 / 13,545 家

  • 全生命周期管理：筛选（经营型 vs 投资型：古茗 vs 霸王茶姬"1+1+9+N"、蜜雪居中）；区域进入（组织先行、模型验证、逐步加密）；持续管理与激励（复投=激励、淘汰=纠偏）
  • 自动化系统降复制难度：茶饮咖啡用硬件替代人工（古茗自动泡茶机、瑞幸全自动咖啡机）；酒店靠管理机制稳定服务品质

A.2.3 品牌建设（柱三）

把"锋利的门店模型 × 广袤下沉市场"积累的规模沉淀为认知与复购：

  1. 调性适配价格带：茶饮靠高频触达、餐饮靠综合塑造、酒店靠长期兑现
  2. 规模即媒介、密度即声量：万店网络本身就是最好的品牌宣传（古茗王云安："每一块招牌都要做成每个小镇街头最亮的那盏路灯"）

A.2.4 数字化能力（一基：底座）

  • 供给侧（供应链与门店管理）：采购/仓配/库存/门店运营从"经验驱动"→"数据驱动"
  • 需求侧（会员运营）：把一次性客流转化为可运营可复购的会员资产

- 会员规模：华住 2.67 亿（2024 末）；锦江/首旅/亚朵 2.1/2.1/1.1 亿（2025 末）；百胜 5.75 亿（3Q25）；蜜雪 4.3 亿（2025 底）

A.3 新万店 vs 老万店：从规模扩张走向健康增长

  • 分野不在是否跨过万店门槛，而在门店网络能否在扩张中持续创造健康回报
  • 增长质量 = 广袤受众市场 × 锋利门店模型；"三柱一基"决定规模能否被稳定承接
  • 两端相互强化 → 门店加密转化为供应链摊薄、加盟商回报、品牌认知提升的正循环；否则万店规模难以转化为持续经营优势

A.4 万店之后：门店复制 → 能力复用

A.4.1 广度：国内加密 + 出海

国内：头部品牌靠拓宽+加密实现超额增长。

  • 蜜雪/瑞幸已验证高密度全国化：500 米内商业据点覆盖率 49%/39%，一级商业据点入驻率 75%/72%，但三级/四级入驻率仅 28%/21%、11%/7% → 下沉仍有空间
  • 业态定位差异：高价咖啡最依赖高线与成熟点位（一线占比 36%）；低价茶饮/量贩零食城市层级约束最弱（一线占比仅 5%/4%）
  • 竞争密度：品牌间门店距离已显著低于单品牌内部距离（高价茶饮品牌间中位仅 67 米），核心商圈加密空间有限
  • 空间测算（低密度城市向现有密度 50%/75% 分位提升）：
品类 基准（50%） 乐观（75%）
茶饮+6%+22%
咖啡+6%+16%
量贩零食+11%+28%

出海：海外市场是突破本土增长约束的重要引擎。

  • 全球门店及海外占比（2025）：麦当劳 4.5 万/70%、KFC 3.4 万/90%、星巴克 4.1 万/55%、达美乐 2.2 万/68%；蜜雪/瑞幸海外占比仅 7%/1%
  • 海外门店 10 年 CAGR 均高于整体增速
  • 三层能力迁移：① 供应链出海（规模采购+集中生产+区域仓配+本地化）；② 运营体系出海（内生扩张/收购整合——华住收购 DH 案例）；③ 文化出海（袁记云饺案例）

A.4.2 深度：品类扩展 / 品质提升 / 品牌升级

  • 品类扩展（做宽）：点位互补（64.8% 茶饮门店 150 米内有咖啡店、69.5% 咖啡门店 150 米内有茶饮店）、时段互补（茶咖错峰）、需求互补
  • 品质提升（做深）：茶饮"真鲜纯"升级 = 释放供应链效率 → 质价比 → 复购与同店增长
  • 品牌升级（向上）：华住以汉庭（4,556 家）/全季（3,565 家，合计约 63%）为底座，收购桔子水晶/花间堂、与雅高合作补高端矩阵

A.4.3 效率：链路压缩 / 规模效应 / 价值链重塑

  • 链路压缩 → 提总部毛利率（集中采购、产地直采、核心原料自产）
  • 规模效应 → 降总部费用率（固定投入摊薄）
  • 价值链重塑 → 新增利润空间（联合定制、专供规格、自有品牌）
  • 量贩零食：由"压缩流通成本、重分存量利润"进入"组织产业链、创造新增价值"第二阶段

A.5 万店投资：成长与价值兼备

  • 二维框架：成长性（扩张/同店/盈利持续性）× 价值性（FCF 质量/分红回购）→ 四象限：稳态回报型 / 扩张回报兼备型 / 扩张再投资型 / 模型再验证型
  • 现金流属性强：餐饮即时支付、应收少、周转快、可占供应商账期；加盟模式让加盟商承担重资本，总部轻资产分享网络增长
  • 估值对比（酒店/餐饮饮品/IP潮玩/在线旅游，10 家海外 vs 8 家中国龙头）：
指标 海外龙头 中国龙头 折价
远期 P/E28.8x13.3x\~54%
2025 EV/EBITDA20.1x11.2x\~44%
餐饮板块 P/E\~29x\~15x—
酒店板块 P/E\~33x\~15x—

A.6 风险提示

  1. 消费需求承压：客流增长放缓、消费意愿下降
  2. 行业竞争加剧：价格战/补贴竞争压制利润率
  3. 管理能力提升不及预期：加盟商管理、督导、组织跟不上扩张

B.1 三个含金量洞察

  1. 规模即媒介、密度即声量：万店把"开店"从成本项变成品牌资产项——密度在积累消费者认知，是规模效应之外的第二重正反馈
  2. 加盟瓶颈迁移：从"招到加盟商"→"持续创造有竞争力的单店回报"；单店UE是万店时代的稀缺品
  3. 强供应链能力优先于大单品创新：低复杂度产品易被抄、口味会迁移，交付体系才是护城河

B.2 泼冷水五条

  1. 规模 ≠ 壁垒：报告承认"老万店动能转弱"但没回答临界点在哪（加密到一定程度会分流存量）
  2. 下沉是低质量增长：一级商业点入驻率已达 75%/72%，剩下的三四级点位 ROI 更低——数字有空间、质量要打折
  3. 估值折价可能折得有理：中国增速更快而 P/E 更低，折价在 PEG 维度更夸张；市场或在对加盟成熟度、治理、增长可持续性定价
  4. 出海证据最弱：蜜雪 7%/瑞幸 1%，案例都是刚起步的小样本；麦当劳用了半个世纪
  5. 加盟激励错位被轻轻带过：总部收入很大部分来自"卖货给加盟商"，短期天然有"多开店、多压货"的冲动

C.1 类比校准

同构：都是供应链打底 + 爆品做锋，靠复购频率不靠客单。

关键差异 = "压货载体"：

RTD 现制茶饮（加盟）
压的是什么经销商物理库存（可囤数月）加盟商的店 + 单店UE
爆雷信号晚、突然（库存看不见）早、但更脏（单店UE公开可算）
共同根源品牌收入结构（sell-in 给渠道/加盟商）天然奖励短期扩张同左

C.2 元气森林剧本抽象化

大单品制造需求脉冲 → 用渠道扩张回应脉冲 → 脉冲退潮 + 全行业跟进 → 渠道库存暴露 → sell-in 崩。

本质：用"扩大供给"回应"一次性的需求脉冲"，脉冲退潮后多建的供给变成库存。前两幕数据全好看（收入记在 sell-in 端），第三幕一次性暴露。

C.3 茶饮版剧本 + 案例

剧本：爆品 → 加速开店 → 单店UE下滑被新加盟商掩盖 → 加盟商停复投 → 新加盟商枯竭 → 收入断崖。

  • 库迪咖啡（最标准）：0→1 万店约两年，靠新加盟商补血，单店UE恶化 + 供应链跟不上（中金报告点名"大单品缺货"）
  • 霸王茶姬（潜在版）：大单品伯牙绝弦占比极高 + 快扩 + 高费用；中金报告在营销费用率统计里悄悄用 24 年数据，"考虑 25 年经营情况不具备可持续性"——一个细信号
  • 鹿角巷（历史原版）：大单品依赖 + 加盟体系失控
  • 一点点 / 书亦等（慢性版）：单店UE被稀释、动能转弱（即"老万店"）

C.4 茶饮版"渠道库存"监测指标

  • 加盟商闭店率 / 转让费 / 二手设备价格（转让费暴跌是最灵敏的先行指标）
  • 招商难度（新加盟商谈判周期拉长）
  • 同店下滑 + 开店增长分叉（增量掩盖存量恶化的直接证据）
  • 补贴 / 免加盟费信号（"承认压货"）

D.1 三层模型

层 是什么 韧性 代表
渠道 / 网络终端网点（RTD）/ 加盟门店（现制）最持久——网络会复利，能跨越大单品→矩阵阶段东鹏（600万+终端）、蜜雪（门店网络）
供应链采购 / 生产 / 仓配 → cost leadership持久——规模 + know-how，提供价格战弹药与利润空间蜜雪全产业链、东鹏 PET 低成本、瑞幸直采烘焙
心智品牌认知、复购、溢价相对不持久——可被广告买走、口味会迁移东鹏"累了困了"（锚定渠道密度）、低温奶"新鲜"

心智的韧性取决于是否锚定在渠道/供应链上：东鹏的"累了困了"因 600 万终端天天强化所以持久；纯靠广告砸出的心智（元气森林早期）脉冲快、退潮快。

D.2 绑定约束原则（核心方法）

三层永远同时存在，但某一阶段只有一层是"绑定约束"——决定增量投入能否转化为持久优势的那层。找企业的第一问：这生意的绑定约束是哪一层？ 把尽调资源集中在绑定层。

生意属性 绑定约束 含义 例子
RTD 大单品渠道产品易抄、心智可买，谁终端多谁赢东鹏 vs 红牛：渠道下沉 + 成本
现制茶饮（加盟）供应链 + 加盟商UE"渠道 = 加盟网络"，单店UE是命门蜜雪（UE 健康飞轮）vs 库迪（透支开店）
低温奶供应链（冷链/效期/区域）物理上做不了全国穿透，moat = 区域密度 + 上游奶源 + 新鲜心智光明 / 区域龙头
高端现制 / 品牌心智 / 品牌直营 + 品牌驱动，渠道自有喜茶；霸王茶姬（待验证）

为什么元气森林 / 库迪会爆：

它们把"增长"做在了非绑定层（元气 = 爆品心智的脉冲、库迪 = 开店规模），但绑定层（供应链 / 渠道根基 / 单店UE）还没建成——把"一次性的需求脉冲"误当成"可持续的渠道优势"。坏企业的共同模式：在非绑定层变现，在绑定层欠账。

D.3 识别好企业 / 坏企业

好企业（绑定层持续加固）：

  • 渠道层：终端/门店数增长的同时，单点产出稳定或上升；渠道库存健康
  • 供应链层：单位成本 gap 持续拉大、毛利率稳定（调价后毛利不变 = 供应链控制力）
  • 增长质量：同店/单点增长 > 新店/新终端增长；加盟商复投率上升、闭店率低位
  • 现金流：OCF/净利润 > 1，营运资本干净

坏企业（非绑定层透支）：

  • 单店UE / 单点产出下滑，但被开店/铺货增速掩盖
  • 渠道库存天数上升（RTD）/ 加盟商转让费暴跌、闭店率上升（现制）
  • 应收/存货增长快于收入（财务表上的压货信号）
  • 同店下滑 + 开店增长并存（增量掩盖存量恶化）
  • 增长放缓时第一反应是补贴渠道 / 免加盟费（"承认压货"）

D.4 定量清单（stats don't lie）

渠道层

  • 终端网点数 / 门店数（绝对量与增速）
  • 单点产出：单点卖力、单店日销、单店UE（现制）
  • 渠道库存天数（sell-in vs sell-through）← 压货先行指标
  • 经销商数量/质量/流失率；加盟商复投率、闭店率、转让费
  • 新区域渗透：新市场密度 vs 当地需求基数（密度分位数法，来自中金万店报告）
  • 区域市占率分布：中位数 vs 90 分位（强者恒强验证）

供应链 / 成本层

  • 单位成本（单箱 / 单杯）与可比公司 gap 及趋势
  • 毛利率水平与稳定性（调价后毛利能否保持）
  • 产能利用率、capex/收入（重资产扩张信号）
  • 履约费用率（物流仓储占比随规模是否下降）

增长质量层

  • 同店增长 vs 门店/终端增长拆分
  • 新区域 vs 成熟区域单店UE / 单点产出
  • FCF 转化率、营运资本变化（应收/存货 vs 收入增速）

心智层

  • 心智份额 vs 市场份额 gap
  • 复购率、会员数/活跃度
  • 终端动销（sell-through，而非 sell-in）

⚠️ 关键提醒：爆雷前多数表内指标"好看"（收入记在 sell-in 端）。要看二阶信号：渠道库存、加盟商复投、单点UE 与新店增速的背离、OCF 与利润的背离。

D.5 定性：创始人 / 团队的 mindset

  • 如何理解终局："让加盟商/经销商赚钱" vs "我要多快铺货 / 多快开店"
  • 团队基因：快消/渠道出身（东鹏·林木勤）vs 互联网/产品出身（元气·唐彬森）——无绝对好坏，但需匹配生意属性（渠道驱动的生意需要渠道型组织）
  • 对供应链的态度：愿不愿为长期成本优势做重投入（自建工厂/产业链），还是外包省事
  • 对慢的理解：快消是慢生意，渠道/供应链是时间的朋友；看创始人是否有"种树"的耐心而非"摘果"的急躁
  • 对增长放缓的第一反应：保护渠道利润 / 修炼单店UE，还是补贴渠道 / 多开店（后者 = 压货信号）
  1. 万店的门槛不在数量，在网络能否自我养活——供应链养出品、单店UE养加盟商、密度养品牌；三者转成正循环才是真万店，否则只是"开了一万家店"
  2. 识别企业的第一问：绑定约束在哪一层——把尽调资源集中在绑定层，其余层验证即可
  3. 坏企业的共同模式：在非绑定层变现，在绑定层欠账——增长的钱投进绑定层是复利，撒在非绑定层是透支
  4. 压货是制度性的（收入结构奖励扩张）——防爆关键不是管住加盟商，而是管住自己开店的冲动；监测靠二阶信号，因为爆雷前表内指标大多好看
  5. 估值折价未必是错杀——中国龙头对海外折价约 54% 可能是对加盟成熟度、治理、增长可持续性的合理定价；规模 ≠ 壁垒
  6. 好企业画像：在绑定层持续加固 + 老加盟商/经销商在复投 + 同店/单点增长健康 + OCF 质量高；管理层在增长放缓时先护渠道利润 / 修炼单店UE，而非补贴扩张
