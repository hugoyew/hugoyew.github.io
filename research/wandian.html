万店连锁：什么样的零售业态能跑通？

从蜜雪到瑞幸：万店连锁背后的渠道、供应链与心智三层识别框架。

执行摘要

  • 万店连锁的本质是"渠道密度 × 供应链效率 × 心智占位"三层飞轮，缺一不可
  • 蜜雪冰城证明了极致性价比模型的天花板：2.5万+店、9元均价、加盟模式跑通
  • 瑞幸证明了数字化运营可以重构咖啡品类：万店后单店模型仍在改善
  • 古茗代表"区域深耕→全国扩张"的茶饮第二梯队路径，供应链是核心壁垒
  • 识别万店潜力的关键：单店模型是否在加密后仍成立、供应链是否随规模线性降本

一、画像

万店连锁 = 用标准化单店模型 + 中心化供应链 + 高密度渠道网络，在一个高频低客单品类里收割规模红利。

不是所有连锁都能万店。万店是一个结果，背后是三个条件同时满足：

  1. 品类足够大——高频、刚需、低决策成本
  2. 单店模型足够轻——加盟可复制、选址容错高、回本周期短
  3. 供应链足够深——随规模线性降本，形成后发者无法追赶的成本壁垒

中国市场的万店样本：蜜雪冰城（2.5万+）、瑞幸（2万+）、华莱士（2万+）、古茗（9000+，冲万店中）。

二、核心论点

2.1 三层飞轮：渠道 → 供应链 → 心智


渠道密度 ↑ → 采购规模 ↑ → 单位成本 ↓ → 价格优势 ↑ → 客流 ↑ → 渠道密度 ↑
                                    ↓
                              心智占位强化

蜜雪的"4元柠檬水"不是定价策略，是供应链规模的结果——2.5万家店的柠檬采购量，让任何竞争对手都无法在同价位盈利。

2.2 蜜雪冰城：极致性价比的天花板

维度 蜜雪冰城
门店数25,000+（全球）
均价~9元
模式加盟为主，总部赚供应链钱
核心壁垒自建工厂 + 22个仓储物流中心
毛利率（总部）~30%（供应链模式）

蜜雪的本质不是茶饮公司，是餐饮供应链公司——门店是渠道，利润来自向加盟商卖原料。这解释了为什么它能在9元均价下仍有健康利润。

2.3 瑞幸：数字化重构咖啡品类

瑞幸证明了两件事：

  1. 万店后单店模型可以继续改善——规模效应 + 数字化选品/定价/选址，让同店销售在万店后仍增长
  2. 咖啡在中国是"功能饮料"而非"社交空间"——9.9元的价格带 + 自提为主，把咖啡从星巴克的"第三空间"变成了日常消费品

瑞幸的壁垒不在咖啡品质，在运营系统——APP订单占比>90%、算法驱动选址、每周上新的产品迭代速度。

2.4 古茗：区域深耕的第二梯队路径

古茗代表了另一条路：不追求全国铺开，先在浙江/福建做到区域密度第一，再逐步外扩。

维度 古茗 蜜雪
门店数~9,00025,000+
均价~15元~9元
区域华东为主全国下沉
供应链区域仓配（1天达）全国22仓

古茗的核心壁垒是区域供应链密度——在浙江，古茗的原料配送时效和成本优于任何全国性品牌。冲万店的关键是：跨区域扩张时，供应链能否同步复制。

2.5 识别框架：什么样的连锁能万店？

检验维度 通过标准 反例
单店回本周期<18个月重资产餐饮（>24个月）
选址容错街边/社区/商场均可仅商场店（受限于商场数量）
供应链规模效应采购量每翻倍，成本降>5%无集中采购的松散加盟
品类频次每周≥1次低频品类（如正餐）
标准化程度无需厨师，SOP可复制依赖厨师手艺

  • 现制饮品的健康化趋势（低糖/无糖）对传统高糖品牌的冲击
  • 加盟模式下的品控风险——万店规模下任何食品安全事件都是系统性风险
  • 自动化设备（制茶机器人）对人力成本的替代节奏

五、总结

  • 万店连锁的本质是供应链公司——门店是渠道，利润来自规模采购和中心化物流。蜜雪是最纯粹的样本。

  • 识别框架：单店回本<18个月 + 选址容错高 + 供应链规模效应 + 高频品类 + 高度标准化。五个条件同时满足才有可能万店。
  • 投资视角：万店不是终点，是新起点——万店后的增长来自海外扩张、品类延伸（蜜雪做幸运咖）、供应链对外输出。

萬店連鎖：什麼樣的零售業態能跑通？

執行摘要

  • 萬店連鎖的本質是"渠道密度 × 供應鏈效率 × 心智佔位"三層飛輪，缺一不可
  • 蜜雪冰城證明瞭極致性價比模型的天花板：2.5萬+店、9元均價、加盟模式跑通
  • 瑞幸證明瞭數字化運營可以重構咖啡品類：萬店後單店模型仍在改善
  • 古茗代表"區域深耕→全國擴張"的茶飲第二梯隊路徑，供應鏈是核心壁壘
  • 識別萬店潛力的關鍵：單店模型是否在加密後仍成立、供應鏈是否隨規模線性降本

一、畫像

萬店連鎖 = 用標準化單店模型 + 中心化供應鏈 + 高密度渠道網絡，在一個高頻低客單品類裏收割規模紅利。

不是所有連鎖都能萬店。萬店是一個結果，背後是三個條件同時滿足：

  1. 品類足夠大——高頻、剛需、低決策成本
  2. 單店模型足夠輕——加盟可複製、選址容錯高、回本週期短
  3. 供應鏈足夠深——隨規模線性降本，形成後發者無法追趕的成本壁壘

中國市場的萬店樣本：蜜雪冰城（2.5萬+）、瑞幸（2萬+）、華萊士（2萬+）、古茗（9000+，衝萬店中）。

二、核心論點

2.1 三層飛輪：渠道 → 供應鏈 → 心智


渠道密度 ↑ → 採購規模 ↑ → 單位成本 ↓ → 價格優勢 ↑ → 客流 ↑ → 渠道密度 ↑
                                    ↓
                              心智佔位強化

蜜雪的"4元檸檬水"不是定價策略，是供應鏈規模的結果——2.5萬家店的檸檬採購量，讓任何競爭對手都無法在同價位盈利。

2.2 蜜雪冰城：極致性價比的天花板

維度 蜜雪冰城
門店數25,000+（全球）
均價~9元
模式加盟爲主，總部賺供應鏈錢
核心壁壘自建工廠 + 22個倉儲物流中心
毛利率（總部）~30%（供應鏈模式）

蜜雪的本質不是茶飲公司，是餐飲供應鏈公司——門店是渠道，利潤來自向加盟商賣原料。這解釋了爲什麼它能在9元均價下仍有健康利潤。

2.3 瑞幸：數字化重構咖啡品類

瑞幸證明了兩件事：

  1. 萬店後單店模型可以繼續改善——規模效應 + 數字化選品/定價/選址，讓同店銷售在萬店後仍增長
  2. 咖啡在中國是"功能飲料"而非"社交空間"——9.9元的價格帶 + 自提爲主，把咖啡從星巴克的"第三空間"變成了日常消費品

瑞幸的壁壘不在咖啡品質，在運營系統——APP訂單佔比>90%、算法驅動選址、每週上新的產品迭代速度。

2.4 古茗：區域深耕的第二梯隊路徑

古茗代表了另一條路：不追求全國鋪開，先在浙江/福建做到區域密度第一，再逐步外擴。

維度 古茗 蜜雪
門店數~9,00025,000+
均價~15元~9元
區域華東爲主全國下沉
供應鏈區域倉配（1天達）全國22倉

古茗的核心壁壘是區域供應鏈密度——在浙江，古茗的原料配送時效和成本優於任何全國性品牌。衝萬店的關鍵是：跨區域擴張時，供應鏈能否同步複製。
