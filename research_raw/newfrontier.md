## 一、案例背景

| 字段 | 内容 |

## 二、估值逻辑链（PPT 38–42）

| 页码 | 内容 | 关键结论 |
|-|-|-|
| **P38** | 平台 × AI 定位象限图 | NF 在右上角，无 directly comparable |
| **P39** | 选通策 / IHH 做锚 + 回归筛选 | **organic ≥ 25x EV/EBITDA** |
| **P40** | 港股 AI 概念 premium（英矽智能类比） | 保守取 **30–35x** 整体 multiple |
| **P41** | 27/28E EBITDA 倒算 | **44–52B 人民币**（base case） |
| **P42** | 高净值客群 top-down | 支撑今日 IPO ≈ **450 亿** |

### P38 — 立独特性

- 象限图：横轴 = 专科 → 综合 → "医疗 + 健康"全资源；纵轴 = AI 深度绑定。NF 独占右上角。
- 亚洲（含美国）主流上市公司中**没有与 NF 完全直接可比**的公司。
- **三个 P**（Patient / Payment / Provider）都深度受益于 NF 的 AI 模型，完全打通：**one user, one patient, one profile**。
- 反衬：其他机构服务碎片化（锦欣 = 生殖专科，"复杂手术就离开平台"）→ NF 以 **AI + comprehensive care / care continuum** 最大化 differentiation。

### P39 — 锚定最高 + 回归成"规律"

- 锚定：选 **通策（Top Choice）和 IHH** 做起点——医疗服务板块**估值倍数最高的两家**（IHH = 马来西亚最大 premium 医疗集团）。
- 回归：所有可比列出来正相关存在但**影响 R²** → 做 selection 让关联最 relevant（保留估值最好的两家）。
- 借喻：18A / 生物医药的 one-year / two-year forward multiple 与未来 growth 相关——**投资人愿意为 growth 买账**。
- 结果：套用 NF 26–27 年 EBITDA growth expectation → **organic 至少 25x EV/EBITDA**。

### P40 — AI 溢价（证据 + 克制）

- 市场现象：港股今年 AI 概念公司享有 premium（英矽智能等），IPO 定价 step-up 与上市后表现都不错。
- 同类稀缺：医疗服务中没有 "AI embedded" 平台，但医药有（英矽智能）→ 用 **PE 逻辑**对比（已盈利多年）。
- 量化锚：英矽智能 vs 传统药企 ≈ **50% PE 溢价**。
- 保守应用：直接 ×1.5 会**远超 35.5x** → 取 **30–35x**（"可以说是拍的，也可以说是 relevant"）。

### P41 — 倒算区间

- 年份口径：现在（26H2）投资人看 one-year-plus = **27E**；预计 **27H2 上市**，届时卖的是 **28E EBITDA** → 按增速倒算。
- 结果：**44–52B 人民币**（organic + AI），定义为 **base case**。
- DCF 必做，但结果不会超出此 framework。

### P42 — Top-down 用户价值交叉验证

| 步骤 | 假设 | 结果 |
|-|-|-|
| 1 | 2035 年中国高净值 household ≈ 1,000 万户 | — |
| 2 | 只 address 10% | 100 万户 |
| 3 | 每户每年医疗消费 6 万元（conservative） | 收入 ≥ 600 亿元 |
| 4 | 成熟 EBITDA margin × 15–20x EV/EBITDA | 1,800–2,400 亿元（2035） |
| 5 | 按 20% IRR 折现回今天 | 支撑今天 400 多亿估值 |

- **交叉印证**：100 万户 × 20% IRR → justify 今天 IPO ≈ **450 亿**（"which is not expensive"）。
- 现状基础：保险侧已有 \~20 万户购买 primary care / healthcare 产品。
- 远期：十年内成为 1,000–2,000 亿 equity value 公司，只需 100 万户 loyal household。

## 三、估值思路链：每页预判下一个攻击性问题

| 步 | 页 | 回答的问题 | 动作 |
|-|-|-|-|
| 1 | P38 | "凭什么给你高估值？" | 先**消灭可比性**，立独特性 |
| 2 | P39 | "倍数从哪来？" | **锚定市场最高** + 回归转成"规律" |
| 3 | P40 | "可比里没有 AI，溢价怎么 justify？" | 到市场**找证据**（英矽） |
| 4 | P41 | "到底多少？" | **倒算区间** 44–52B |
| 5 | P42 | "42B 是不是太贵？" | 换 top-down **重新定义贵** |

> 核心特征：**先把最容易被攻击的"没有可比"主动摆上台面，再逐层建防御**——每一页都在回答对手下一句要问的话。

## 四、Storytelling 手法（可复用）

1. **独特性先行**：谈数字之前先让"我们没有可比"成立，估值锚从"市场均价"变成"自己定义的稀缺"。
2. **锚定效应**：从市场倍数最高的公司起步，不从中间开始。
3. **借喻成熟逻辑**：拿 18A / biotech 的 forward multiple 类比，让"为增长付溢价"显得是市场惯例而非自嗨。
4. **证据 + 克制双保险**：溢价必须有市场证据，但应用时留 buffer（30–35x 而非直接 ×1.5）。
5. **双层叙事**：base case（可 defend）与 aspirational（激励）刻意分离，不用愿景当承诺。
6. **重新定义"贵"**：数字高时不辩解数字，换方法论（top-down 用户价值）重算——"which is not expensive"。
7. **保守修辞包装进取结论**："只 address 10%"、"6 万很保守"、"至少 25x"。

## 五、提炼：四步通用估值框架

**定方法 → 选可比 → 验证溢价 → 交叉验证**

| 步 | 框架动作 | 本 case 落地 |
|-|-|-|
| 1 | **定方法**（comps / PE / EV/EBITDA / PEG…） | 刚盈利 → EV/EBITDA；未盈利用远期；成熟用 PE/PEG |
| 2 | **选可比** | 分板块选 5 家回归；锚定通策 / IHH；selection 保 R² |
| 3 | **验证溢价**（稀缺 / 壁垒 / 品牌 / 生态） | AI premium：市场证据 + 同类稀缺 + 量化锚 + 保守应用 |
| 4 | **交叉验证**（倒算 / topdown / bottomup，IRR / DCF / assumption） | P41 倒算 ↔ P42 topdown；DCF 不超框架 |

## 六、Stock pitch 结构（定量 + 定性结合）

**定性的壳 → 定量的核 → 定性的收尾**

1. **开场定性立独特性**（P38）：没有可比 + 右上角 + 压缩叙事（one user, one patient, one profile）+ 反衬。
2. **定量给数字**（P39–41）：锚定最高倍数 → 回归成"规律" → 溢价有证据且克制 → 倒算区间。每个定量选择都在为叙事服务。
3. **收尾定性重新定义**（P42）：数字显得贵 → 换一把尺子重算，把 42B 翻译成"只需 100 万忠实客户"。

## 七、可复用 Checklist

- [ ] 方法是否匹配盈利阶段？（未盈利 → PS / 远期；刚盈利 → EV/EBITDA；成熟 → PE / PEG）

- [ ] 无可比时是否分板块 + 回归？锚定最高倍数？selection 是否有 R² 逻辑？

- [ ] 溢价是否有证据 + 克制？（市场现象 / 同类稀缺 / 量化锚 / 保守区间）

- [ ] 年份口径是否一致？（现在看 27E，上市卖 28E）

- [ ] 是否有 base case 与 aspirational 分层？

- [ ] 是否用 top-down / DCF 交叉验证？（IRR 折现、用户价值翻译）
