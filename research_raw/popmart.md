## 一、本周研究结论

### 它是什么

泡泡玛特 = **IP 投资引擎 + 全球化零售渠道**。不卖内容，不卖玩具，卖的是"情绪的容器"。

类比：**腾讯投资的逻辑**——渠道（微信生态 / 630 家门店）已铺好，每孵化成功一个 IP ≈ 边际成本趋零的纯增量利润。但 P&L 本质是制造业零售，不是 VC。

### 五个核心判断

**① 壁垒不在盲盒，不在某个 IP，在效率三角。**

$$\text{护城河} = \text{IP 投资能力} \times \text{渠道品质感} \times \frac{\text{高客单}}{\text{低费率}}$$

产品形态（盲盒→毛绒→搪胶→未来任何东西）是平权的，换一个形态三角不变就成立。小家电破坏三角的每一条边——方向错误。

**② 渠道能力是 DTC 闭环型，不是 LEGO 型也不是 Jellycat 型。** *(v4 新增)*

| 对标 | 模式 | 与 PPMT 的关系 |
|-|-|-|
| LEGO | 品牌力外溢 → 进一切渠道 | PPMT 品牌还没强到这一步 |
| Jellycat | 品牌升维 → 收缩渠道造稀缺 | PPMT 已在做（DTC + 体验式零售） |
| TOP TOY | 母公司开店能力复制，毛利率仅 32% | **反面教材**：没有 IP 就没有定价权 |
| **PPMT** | **IP × DTC 闭环** → 数据驱动选品 | DTC 占比 70%+，630 店是"品牌教堂"，不是走量 |

**③ 联名是新时代 IP 的核心触点，正在重构生命周期。**

过去 IP 触点围绕影视（高成本、低频、脉冲式），现在核心触点是联名（低成本、高频、连续式）。每一次联名 = 一次 IP 生命周期的"重置"。FIFA 世界杯联名的核心价值不是收入，是 60 亿观众级别的触点注入——**不但不花钱，还赚钱的"广告"**。

**④ 三丽鸥是参考但不是目标——PPMT 不该做三丽鸥。** *(v4 修正)*

共同点：无叙事符号 × 渠道运营。差异：三丽鸥靠轻资产授权（60%+），ppmt 靠重渠道自营 DTC（授权仅 \~3%）。

> [!important] v4 关键修正  
> 授权不需要做大。多了是**消耗 IP 价值**——到处印 logo = 稀缺感崩塌。授权占比从 3% → 5-8% 是自然溢出，健康的。>15% 就过度了。PPMT 的价值在 DTC 渠道的品牌溢价和体验，不在轻资产授权。

**⑤ "造星 SOP"是伪命题，"赛马机制"是真命题。**

2026Q1 新 IP（Supertutu、KeyA）遇冷证明了不存在确定性的爆款制造。但只要赛马机制运转——失败的快退、成功的快放大——每 2-3 年押中一个 LABUBU 级 IP，增长就能延续。当前问题：缺"优雅退场"机制，LABUBU 占比 38% 偏高（三丽鸥 HK 高峰期 76%→现 \~30%）。

**⑦ 情绪经济的本质不变，载体会变。**

从巫术面具到 Hello Kitty 到 LABUBU——人永远需要把抽象的孤独感变成一个摸得到的东西。AI native 一代可能更孤独，物理锚点更珍贵。但载体会迭代——10 后可能不要盲盒，要 phygital 可交互物件。

## 三、财务预测 & 估值

### 3.1 三年营收测算（IP 弱周期情景）

**核心假设：** LABUBU 年降 15%、核心 IP +10%、每年跑出 1 个 ZSIGA 量级（\~10 亿）新 IP、海外增速阶梯回落。

|-|-|-|-|-|
| 营收（亿） | 371 | \~446 | \~520 | \~598 |
| YoY | +185% | +20% | +17% | +15% |
| LABUBU | 142 | 120 | 102 | 90 |
| 新 IP 累计增量 | 0 | 17 | 35 | 58 |
| 海外占比 | 43.8% | \~47% | \~50% | \~52% |
| **3Y CAGR** |  |  |  | **\~17%** |

### 3.2 用户侧 TAM 校验

$$\text{Revenue}_{2028} = 1.1\text{亿人} \times \text{¥600 ARPU} = 660\text{亿}$$

IP 侧测算 598 亿 < TAM 上限 660 亿 → 未触碰人群天花板。  
频次天花板（<6 次/年）对应极限 ARPU \~¥1,050 → 物理天花板 \~1,150 亿。

#### 方法 A：DCF（绝对估值）

**方法 A-1：净利润折现（粗算）**

两阶段模型：5 年显性预测期 + 永续增长。WACC 12%, g 4%。

| 年份 | 净利（亿） | 折现因子 | PV（亿） |
|-|-|-|-|
| FY2026E | 157.0 | 0.893 | 140.2 |
| FY2027E | 183.7 | 0.797 | 146.4 |
| FY2028E | 211.3 | 0.712 | 150.3 |
| FY2029E | 236.7 | 0.636 | 150.4 |
| FY2030E | 260.3 | 0.567 | 147.7 |
| **合计** |  |  | **735** |

\$\$ \boxed{\text{净利润 DCF 目标价} \approx \text{HK\$206}}  
\$\$

**方法 A-2：FCFF 折现（财务模型）** *(v5 新增)*

用 EBIT(1-t) + D&A - Capex - ΔWC 推算自由现金流，WACC 取 11.2%（Ke 12% × 90% + Kd 3.85% × 10%）。

| 年份 | FCFF（亿） | 折现因子 | PV（亿） |
|-|-|-|-|
| FY2026E | 147 | 0.899 | 132.2 |
| FY2027E | 173 | 0.809 | 139.9 |
| FY2028E | 200 | 0.727 | 145.4 |
| FY2029E | 218 | 0.654 | 142.6 |
| FY2030E | 235 | 0.588 | 138.2 |
| **合计** |  |  | **698** |

\$\$ \boxed{\text{FCFF DCF 目标价} \approx \text{HK\$220}}  
\$\$

**两种方法对比：**

|  | 净利润 DCF | FCFF DCF | 差异来源 |
|-|-|-|-|
| WACC | 12% | 11.2% | FCFF 法加入了债务结构 |
| 目标价 | HK\$206 | HK\$220 | WACC 低 80bp → 估值高 \~7% |
| 如果统一 WACC=12% | HK\$206 | **HK\$203** | 几乎一致 → 净利≈FCFF（因 D&A≈Capex） |

> [!tip] 结论  
> 两种方法在同一 WACC 下结果高度一致（HK$203 vs HK$206）。说明泡泡玛特当前阶段 D&A 与 Capex 大致匹配，净利润是 FCFF 的合理近似。但如果未来重资本投入（乐园、工厂）使 Capex 显著高于 D&A，两者会分化——届时以 FCFF 为准。

**DCF 敏感性矩阵（目标价 HK\$）：**

|  | g = 2% | g = 3% | g = 4% | g = 5% |
|-|-|-|-|-|
| **WACC 9%** | 235 | 279 | 346 | 455 |
| **WACC 10%** | 202 | 233 | 277 | 342 |
| **WACC 11.2%** | 174 | 196 | **220** | 258 |
| **WACC 12%** | 162 | 180 | 203 | 234 |
| **WACC 15%** | 121 | 130 | 141 | 155 |

> WACC 15% + g 4% ≈ HK\$141，恰好是当前价格。 >

#### 方法 C：市场在用什么逻辑？这轮下跌的底在哪？

**3/25 暴跌的市场逻辑重构：**

```Plaintext
财报前市场共识：
  PPMT = 高成长消费股 → PE 30-40x → 股价 HK$300+

3/25 财报发布：
  "营收 +185%，指引 ≥20%"
  → 市场解读："增速从 185% 骤降到 20%"
  → 二阶导转负 → 成长股估值体系崩塌
  → 叠加股息率下调（35%→25%）= 资金信号不佳
  → 单日 -20%+

当前市场正在做的事：
  从"成长股 PE 30-40x"→ 切换到"消费品 PE 12-18x"
  这个切换过程还没走完
```

**底部推演——三个锚：**

| 锚 | 逻辑 | PE | 对应股价 | 备注 |
|-|-|-|-|-|
| **估值锚①：消费品底** | 市场完全不给成长溢价，按纯消费品给 PE | 10-12x | **HK\$101-122** | 极端悲观，需要 LABUBU 崩盘 + 新 IP 全面失败 |
| **估值锚②：DCF 底** | WACC 15% + g 3%（市场极度怀疑） | \~12x | **HK\$125** | 隐含"你只是一个普通消费品公司" |
| **估值锚③：Forward PE 底** | FY2026E 净利 157 亿，给 10x forward PE | 10x fwd | **HK\$122** | 如果 2026H1 数据验证增速确实 ≥20%，这个价格撑不住 |

> [!warning] 底部判断  
> **三个锚交汇区间 = HK\$120-125。** 这是"极端悲观但不是末日"的价格——对应的隐含假设是"泡泡玛特就是一个普通消费品公司，IP 能力没有平台溢价"。

> 当前 HK\$141.8 距离这个底部还有 **\~12-15%** 的下行空间。

> 但如果 2026H1 数据验证了 ≥20% 增速（特别是 FIFA 联名贡献 + 海外不失速），市场会重新给回成长估值——PEG=1 的 HK\$172 就是第一个向上的锚。

#### 估值总结

|  | 预期底价 | 现价 | PEG=1 | DCF(净利) | DCF(FCFF) | 分析师均价 |
|-|-|-|-|-|-|-|
| **价格** | **HK\$122** | **HK\$141.8** | **HK\$172** | **HK\$206** | **HK\$220** | HK\$280 |
| PE | 12x | 14x | 17x | 20x | 22x | 28x |
| 隐含态度 | 纯消费品 | 半信半疑 | 合理成长 | IP平台(保守) | IP平台(中性) | 全面乐观 |
| vs 现价 | **-14%** | — | **+21%** | **+45%** | **+55%** | +97% |

> **我们的判断：**

- **预期底价 HK\$122**：三个估值锚的交汇点。除非 LABUBU 崩盘 + 新 IP 全灭，不太可能跌穿。
- \*\*目标价 HK$172-220**：PEG=1（HK$172）→ 净利DCF（HK$206，WACC 12%）→ FCFF DCF（HK$220，WACC 11.2%）。两种 DCF 在统一 WACC 下结果一致（\~HK\$203），说明净利润是 FCFF 的合理近似。
- **催化剂**：2026H1 中报（≥20% 增速验证）、FIFA 联名落地、新 IP 跑出。
