# 万店连锁 × 识别框架

## 一、画像

万店连锁 = **用标准化单店模型 + 中心化供应链 + 高密度渠道网络，在一个高频低客单品类里收割规模红利**。

不是所有连锁都能万店。万店是一个结果，背后是三个条件同时满足：
1. **品类足够大**——高频、刚需、低决策成本
2. **单店模型足够轻**——加盟可复制、选址容错高、回本周期短
3. **供应链足够深**——随规模线性降本，形成后发者无法追赶的成本壁垒

中国市场的万店样本：蜜雪冰城（2.5万+）、瑞幸（2万+）、华莱士（2万+）、古茗（9000+，冲万店中）。

## 二、核心论点

### 2.1 三层飞轮：渠道 → 供应链 → 心智

```
渠道密度 ↑ → 采购规模 ↑ → 单位成本 ↓ → 价格优势 ↑ → 客流 ↑ → 渠道密度 ↑
                                    ↓
                              心智占位强化
```

蜜雪的"4元柠檬水"不是定价策略，是供应链规模的结果——2.5万家店的柠檬采购量，让任何竞争对手都无法在同价位盈利。

### 2.2 蜜雪冰城：极致性价比的天花板

| 维度 | 蜜雪冰城 |
|-|-|
| 门店数 | 25,000+（全球） |
| 均价 | ~9元 |
| 模式 | 加盟为主，总部赚供应链钱 |
| 核心壁垒 | 自建工厂 + 22个仓储物流中心 |
| 毛利率（总部） | ~30%（供应链模式） |

蜜雪的本质不是茶饮公司，是**餐饮供应链公司**——门店是渠道，利润来自向加盟商卖原料。这解释了为什么它能在9元均价下仍有健康利润。

### 2.3 瑞幸：数字化重构咖啡品类

瑞幸证明了两件事：
1. **万店后单店模型可以继续改善**——规模效应 + 数字化选品/定价/选址，让同店销售在万店后仍增长
2. **咖啡在中国是"功能饮料"而非"社交空间"**——9.9元的价格带 + 自提为主，把咖啡从星巴克的"第三空间"变成了日常消费品

瑞幸的壁垒不在咖啡品质，在**运营系统**——APP订单占比>90%、算法驱动选址、每周上新的产品迭代速度。

### 2.4 古茗：区域深耕的第二梯队路径

古茗代表了另一条路：不追求全国铺开，先在浙江/福建做到区域密度第一，再逐步外扩。

| 维度 | 古茗 | 蜜雪 |
|-|-|-|
| 门店数 | ~9,000 | 25,000+ |
| 均价 | ~15元 | ~9元 |
| 区域 | 华东为主 | 全国下沉 |
| 供应链 | 区域仓配（1天达） | 全国22仓 |

古茗的核心壁垒是**区域供应链密度**——在浙江，古茗的原料配送时效和成本优于任何全国性品牌。冲万店的关键是：跨区域扩张时，供应链能否同步复制。

### 2.5 识别框架：什么样的连锁能万店？

| 检验维度 | 通过标准 | 反例 |
|-|-|-|
| 单店回本周期 | <18个月 | 重资产餐饮（>24个月） |
| 选址容错 | 街边/社区/商场均可 | 仅商场店（受限于商场数量） |
| 供应链规模效应 | 采购量每翻倍，成本降>5% | 无集中采购的松散加盟 |
| 品类频次 | 每周≥1次 | 低频品类（如正餐） |
| 标准化程度 | 无需厨师，SOP可复制 | 依赖厨师手艺 |

## 四、风险与待验证

### 高优先级

| # | 问题 | 为什么重要 | 如何验证 |
|-|-|-|-|
| 1 | 蜜雪海外扩张的单店模型能否复制？ | 国内饱和后增长靠海外 | 跟踪东南亚门店数/单店营收 |
| 2 | 古茗跨区域扩张时供应链能否跟上？ | 区域优势≠全国优势 | 跟踪华南/华北门店密度和闭店率 |
| 3 | 瑞幸9.9元价格战的盈利底线在哪？ | 长期低价可能侵蚀利润 | 跟踪季度毛利率和同店销售 |
| 4 | 茶饮行业是否已到存量竞争？ | 万店后增长逻辑变了 | 跟踪行业总门店数和闭店率 |

### 中优先级

- 现制饮品的健康化趋势（低糖/无糖）对传统高糖品牌的冲击
- 加盟模式下的品控风险——万店规模下任何食品安全事件都是系统性风险
- 自动化设备（制茶机器人）对人力成本的替代节奏

## 五、总结

- **万店连锁的本质是供应链公司**——门店是渠道，利润来自规模采购和中心化物流。蜜雪是最纯粹的样本。
- **三条路径**：极致性价比（蜜雪）、数字化运营（瑞幸）、区域深耕（古茗）。三条路都能万店，但壁垒来源不同。
- **识别框架**：单店回本<18个月 + 选址容错高 + 供应链规模效应 + 高频品类 + 高度标准化。五个条件同时满足才有可能万店。
- **投资视角**：万店不是终点，是新起点——万店后的增长来自海外扩张、品类延伸（蜜雪做幸运咖）、供应链对外输出。
